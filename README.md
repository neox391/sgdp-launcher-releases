# SGDP Launcher

Launcher Windows 64 bits pour SGDP — Saison 2.

## Télécharger

**[Télécharger la dernière version](https://github.com/neox391/sgdp-launcher-releases/releases/latest)**

Ouvrir la release, puis télécharger `SGDP-Launcher-Setup-….exe` dans **Assets**. Fermer le launcher avant installation.

Java 25 et les 43 mods du pack sont inclus. Minecraft 26.3 et Fabric 0.19.5 sont installés au premier lancement du jeu. Un compte Microsoft possédant Minecraft Java et une connexion Internet sont nécessaires.

## Mises à jour

Installer la version **0.5.4 ou ultérieure une fois** pour activer les mises à jour depuis GitHub. Les anciennes versions utilisent encore l’ancien serveur.

Ensuite, le launcher vérifie les versions au démarrage et télécharge automatiquement les mises à jour. Le bouton « Installer et relancer » apparaît lorsque le téléchargement est terminé. Une mise à jour téléchargée peut aussi être installée à la fermeture.

Ce dépôt contient uniquement les téléchargements et les informations de distribution. Les sources sont maintenues dans un dépôt privé. Les fichiers tiers conservent les licences de leurs auteurs.
